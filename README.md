# 📰 Daily Bugle Press Pass Generator

An interactive, high-resolution web editor for customizing and generating authentic 2002 Sam Raimi *Spider-Man* inspired **Daily Bugle Press Passes**.

🌐 **Live Demo:** [https://adwaitgaonkar.github.io/daily-bugle-press-pass/](https://adwaitgaonkar.github.io/daily-bugle-press-pass/)

---

## ✨ Features

- 📐 **Exact Physical Card Proportions**: Fixed physical dimensions of **2.63" × 3.88"** ($340\text{px} \times 502\text{px}$ live preview, aspect ratio $\approx 0.6778$).
- 📰 **Authentic Typography & Editorial Styling**:
  - Classic Daily Bugle logo masthead banner.
  - Refined **Playfair Display** serif font for *J. Jonah Jameson*.
  - Clean uppercase editorial title (*EDITOR-IN-CHIEF • THE DAILY BUGLE*).
  - Handwritten cursive signature in **Brittany Signature** script font.
  - Warm off-white card tone (`#F7F5ED`).
- 📊 **Dynamic Code-128 Barcode Generator**: Generates real scannable Code-128 barcodes from any 10-digit badge ID.
- 🔘 **Top Punch Slot Option**: Toggle **Top Punch Slot (Yes — Show / No — Hide)** for lanyard slotting.
- 🖨️ **High-Res 300 DPI PNG Exports**: Native HTML5 Canvas exporter renders crisp **$1052 \times 1552\text{px}$ (300 DPI)** PNG files for double-sided physical card printing.

---

## 🛠️ Tech Stack

- **HTML5** & **CSS3** (Flexbox, CSS Grid, Custom Properties)
- **Vanilla JavaScript (ES6+)**
- **HTML5 Canvas API** (High-DPI 300 DPI Exporter)
- **Google Fonts & CDN Fonts** (*Anton*, *Oswald*, *Playfair Display*, *PT Sans*, *Brittany Signature*)

---

## 🚀 Quick Start

No build step or Node dependencies required!

```bash
# Clone the repository
git clone https://github.com/adwaitgaonkar/daily-bugle-press-pass.git

# Navigate into project directory
cd daily-bugle-press-pass

# Open index.html in your default web browser
open index.html
```
