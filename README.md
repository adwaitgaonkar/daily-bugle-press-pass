# Daily Bugle Press Pass Generator 📰

An interactive, high-resolution web editor for generating authentic 2002 Sam Raimi *Spider-Man* inspired **Daily Bugle Press Passes**.

Created & Developed by **Adwait Gaonkar**.

---

## ✨ Features

- **Exact Physical Card Proportions**: Fixed physical dimensions of **2.63" × 3.88"** ($340\text{px} \times 502\text{px}$ live preview, aspect ratio $\approx 0.6778$).
- **Authentic Typography & Styling**:
  - Classic Daily Bugle logo masthead banner.
  - Refined **Playfair Display** serif font for *J. Jonah Jameson*.
  - Clean uppercase editorial credential title (*EDITOR-IN-CHIEF • THE DAILY BUGLE*).
  - Handwritten cursive signature in **Brittany Signature** script font.
  - Warm off-white card tone (`#F7F5ED`).
- **Dynamic Code-128 Barcode Generator**: Generates real scannable Code-128 barcodes from any 10-digit badge ID.
- **Top Punch Slot Option**: Toggle **Top Punch Slot (Yes — Show / No — Hide)** for lanyard slotting.
- **High-Res 300 DPI PNG Exports**: Native HTML5 Canvas exporter renders crisp **$1052 \times 1552\text{px}$ (300 DPI)** PNG files for double-sided physical card printing.

---

## 🚀 How to Run Locally

No build step or Node dependencies required!

1. Clone or download this repository.
2. Open `index.html` in any web browser (Chrome, Safari, Firefox, Edge).
3. Customize your Name, Title, Headshot Photo, and 10-Digit Badge ID.
4. Click **Front PNG** or **Back PNG** to download 300 DPI high-res images, or **Print Double-Sided** to print immediately!

---

## 🛠️ GitHub Pages Deployment

To host this live on GitHub Pages for free:

1. Go to your repository on GitHub.
2. Click on **Settings** > **Pages** (in the left sidebar).
3. Under **Build and deployment** > **Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**.
5. Your press pass generator will be live at `https://<your-username>.github.io/<your-repo-name>/`!
